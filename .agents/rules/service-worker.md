# Service Worker & PWA Guidelines (Zero SW Libraries)

## 1. STRICT RULE — NEVER USE SERVICE WORKER LIBRARIES
- **NEVER** install, re-introduce, or use any third-party Service Worker or PWA libraries (e.g. `@serwist/next`, `serwist`, `next-pwa`, `workbox`, `@ducanh2912/next-pwa`, etc.).
- **NEVER** wrap Next.js configurations (`next.config.ts` or `next.config.js`) with service worker compiler plugins (like `withSerwist` or `withPWA`).
- The AI agent must proactively reject or remove any attempt to add service worker libraries.

## 2. RATIONALE & ARCHITECTURAL INVARIANTS
1. **Turbopack Incompatibility:** Modern Next.js 15+ and 16+ use Turbopack by default. Third-party service worker libraries rely on custom Webpack compilation hooks, forcing `--webpack` fallback builds that significantly slow down development and build times.
2. **Stale Caching & Chunk Load Failures:** Aggressive offline precaching manifests generated by service worker libraries frequently cause `ChunkLoadError` and stale page mismatches upon deploying new versions.
3. **Session & Realtime Conflicts:** Automatic service worker fetch interception frequently interferes with dynamic Server Components, Better Auth authentication cookies, and real-time WebSocket/Convex database sync.
4. **PWA Installability Works Natively:** Modern browsers only require a Web App Manifest (`manifest.ts` or `manifest.json`) and appropriate icons to trigger app installation. Aggressive offline asset caching is neither required for installability nor desirable for real-time cloud-backed web apps.

## 3. WEB PUSH NOTIFICATIONS (NATIVE VANILLA ONLY)
- If the application supports Web Push Notifications, use **strictly a single vanilla JavaScript file** located at `public/sw.js`.
- `public/sw.js` must have **zero external libraries**, zero npm dependencies, and zero build compilation steps.
- The file must contain only native browser Web Push event listeners:
  - `self.addEventListener("push", ...)`
  - `self.addEventListener("notificationclick", ...)`
- Register the service worker cleanly from the client using the native Web API:
  ```typescript
  if (typeof window !== "undefined" && "serviceWorker" in navigator) {
    const registration = await navigator.serviceWorker.register("/sw.js", { scope: "/" });
    await navigator.serviceWorker.ready;
  }
  ```
