# Project Versioning Rules

- Gunakan **Calendar Versioning (CalVer)** dengan format **`YYYY.M.D`** (contoh: `2026.9.12`).
- Wajib memperbarui versi di `package.json` setiap kali ada perubahan pada proyek.
- DILARANG menggunakan format SemVer atau `YYYY.M.PATCH`. Digit terakhir merepresentasikan tanggal/hari (`D`), bukan counter patch.
